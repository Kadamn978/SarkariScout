### Key Insight

**Most government sources (80%+) DO NOT post job notifications on social media.**

- Only SSC (@SSC_GoI) and IBPS (@ibps_official) actively post on X
- UPSC uses LinkedIn (not X/Instagram)
- Defence services post rarely (operational content, not jobs)
- State PSCs have NO social media presence for jobs

**Implication for SarkariScout:**
1. Web scraping remains the PRIMARY method for job discovery
2. Social media monitoring is SECONDARY (for SSC, IBPS, defence)
3. Our value proposition is STRONGER because we aggregate from websites that competitors don't monitor

### Monitoring Tools

1. **X API** (Free tier: 1,500 tweets/month)
   - Track @SSC_GoI, @ibps_official, @indiannavy, @IAF_MCC, @DRDO_India
   - Filter for job-related keywords

2. **RSS Feeds** (if available)
   - UPSC LinkedIn RSS
   - YouTube channel RSS

3. **Web Scraping** (for YouTube)
   - Monitor video titles for "recruitment", "vacancy", "apply"

### Alert Workflow

```
Social Media Post Detected
    ↓
Extract Job Details (title, dates, link)
    ↓
Check if already in database (dedup)
    ↓
If new → Create job entry
    ↓
Send instant alert to subscribers
    ↓
Add to daily digest
```
